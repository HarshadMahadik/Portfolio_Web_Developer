MangaVerse – Comic & Manga Website

MangaVerse

2024 Frontend Project Live on Vercel 24+ Manga Titles
24+ Manga Titles Multiple Categories Fully Responsive Deployed on Vercel

MangaVerse is a fully responsive manga and comic reading website built entirely with HTML, CSS, and Vanilla JavaScript — no frameworks, no libraries. The site features a clean, media-rich layout inspired by modern streaming platforms.


The home page features a hero slider section showcasing top titles like One Piece, Naruto, and Black Clover with large cover art and story summaries. A "Popular Choice" grid and "Underrated Picks" section organize 24+ manga titles into scannable card layouts. Each manga card links to a dedicated detail page (e.g., /Pages/OnePiece.html) with chapter info.


The site includes a working search bar, a Manga listing page, and a Category browsing page — giving users multiple ways to discover new titles. The navigation is sticky with smooth transitions, fully collapsing on mobile.

Key Features

  • Hero banner with 3 featured manga and descriptions
  • Popular Choice grid — 12 top manga with cover images
  • Underrated Picks section — 12 lesser-known titles
  • Individual manga detail pages for each title
  • Dedicated Manga listing page with all titles
  • Category browsing page
  • Search bar functionality
  • Sticky responsive navigation
  • Mobile-first responsive design
  • Deployed and live on Vercel
